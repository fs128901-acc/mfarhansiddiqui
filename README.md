# Muhammad Farhan Siddiqui — Website V4

A responsive, GitHub Pages-ready professional website for Muhammad Farhan Siddiqui and Siddiqui's Accounting Services.

## Deploy on GitHub Pages
1. Extract the ZIP.
2. Upload all files and folders to the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`, then save.
5. Wait a few minutes and refresh your GitHub Pages URL.
